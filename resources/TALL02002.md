# 查看Maya中的类型列表


你是否还在为场景中有那些类型的节点而苦恼？
请使用本文中的方法查询你的Maya中到底存在着那些类型的节点。


```python
import maya.cmds as cmds

def get_all_node_types():
    # 使用 cmds.allNodeTypes 获取所有节点类型
    node_types = cmds.allNodeTypes()
    return node_types

# 调用函数并打印所有节点类型
all_node_types = get_all_node_types()
print("\n".join(all_node_types))

```
