# 使用userSetup.py初始化Maya

配置userSetup.py文件可以在启动Maya时初始化资源。

可以在 maya.env 文件中设置或扩展 PYTHONPATH，例如：

```
MAYA_SCRIPT_PATH = D:\MyMayaScripts;
```

## 初始化自定义菜单  

```python
import maya.cmds as cmds
import maya.mel as mel
import maya.utils


def create_my_menu():
    # 如果菜单已存在，则先删除，避免重复加载
    if cmds.menu("myCustomMenu", exists=True):
        cmds.deleteUI("myCustomMenu", menu=True)

    # 获取主窗口名称
    main_window = mel.eval('$tmpVar=$gMainWindow')

    # 在主窗口上创建菜单
    my_menu = cmds.menu("myCustomMenu", label="My Tools", parent=main_window, tearOff=True)

    # 添加菜单项
    cmds.menuItem(label="工具1", command=lambda *args: cmds.confirmDialog(title="提示", message="工具1被点击"))
    cmds.menuItem(label="工具2", command=lambda *args: cmds.confirmDialog(title="提示", message="工具2被点击"))


# 延迟执行，确保 Maya 主窗口已生成
maya.utils.executeDeferred(create_my_menu)

```
